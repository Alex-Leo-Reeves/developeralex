New Release Desktop + server system

Rocca DCO Filesystem

A peer-to-peer office file sharing system with a Node.js server and two Flutter Windows desktop apps. Plug a USB drive into the admin PC to turn it into a LAN hub — the Admin App manages users, files, locks, chat, and subscriptions, while the User App lets staff browse files, view/edit PDFs and Office docs, chat, and share files by Office ID via WebSocket real-time sync. No cloud or internet required.
